Ferramentas didáticas

Laboratório de Guematria

Experimente o valor numérico das letras hebraicas no sistema padrão. A ferramenta é educativa e não determina, por si só, o significado de um texto.

Digite letras hebraicas para calcular.

Como interpretar o resultado?

O cálculo soma os valores numéricos das letras reconhecidas. A interpretação exige verificar o contexto, o método de cálculo e as fontes tradicionais relevantes.

Sistema padrão: א=1…ט=9; י=10…צ=90; ק=100, ר=200, ש=300, ת=400. Letras finais recebem os valores de suas letras correspondentes.
